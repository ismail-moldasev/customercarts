# Mal Cards

Одностраничный офлайн-конструктор карточек для сделок с живым скотом, мясом и молочной продукцией.

## Возможности

- переключение между карточкой продавца и клиента;
- отдельные формы для живого скота, мяса и молочной продукции;
- динамические поля по виду, полу и возрасту животного;
- живой предпросмотр готовой карточки;
- сохранённые карточки и история версий;
- восстановление, редактирование, копирование и удаление карточек;
- автоматическое сохранение черновика в `localStorage`;
- миграция данных из старых ключей `my-cards`, `favorites` и `history`;
- работа без сервера, регистрации и интернет-зависимостей.

## Запуск

Можно просто открыть `index.html` в браузере. Для локальной разработки также подойдёт любой статический сервер:

```bash
python3 -m http.server 8000
```

После этого откройте `http://localhost:8000`.

## Хранение данных

Приложение не отправляет данные в сеть. Черновик, сохранённые карточки и до 50 последних версий хранятся только в `localStorage` текущего браузера.

Используемые ключи:

- `livestock-card-creator:v2:draft`
- `livestock-card-creator:v2:saved`
- `livestock-card-creator:v2:history`
